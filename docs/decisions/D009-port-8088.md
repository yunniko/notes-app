# D009 · The app is published on 127.0.0.1:8088
Date: 2026-11-02 · Goal: G-001 M3 · Status: active (superseded by: —)
Context: the stack needs one host port for nginx, and 8080 was already in use on the development machine.
Decision: default `APP_PORT=8088`, overridable in `.env`. MariaDB is published on 127.0.0.1:3307 only for local tooling.
Force: tie-break — any free port works, and binding to 127.0.0.1 is what matters.
Rejected: 8080 (taken locally, and the most common collision); 80 (needs privileges on some systems).
Consequence: none beyond consistency, since the README, `.env.example` and the Vite and Playwright configs use the same default.
Evidence: `.env.example`; `docker-compose.yml`
